# RIYAD BIKE 🏍️

A modern and responsive motorcycle showroom website built to showcase popular motorcycles available in Bangladesh.

RIYAD BIKE provides a simple way for users to explore motorcycle models, check their basic specifications, view estimated prices, and save their favorite bikes.

## About the Project

RIYAD BIKE is a motorcycle showroom website developed as part of an IT Project Management project. The main goal is to create a clean and user-friendly online platform where customers can explore different motorcycle models.

The website focuses on popular motorcycle models such as Bajaj Pulsar, TVS Apache RTR, Yamaha FZ-S V3, Honda Hornet, and Suzuki Gixxer.

The design focuses on simplicity and usability so visitors can browse motorcycles without dealing with a complicated interface.

## How It Works

The website displays motorcycle information from a JavaScript product data collection.

Users can search for motorcycles, filter them by category, and sort the available products. They can also add motorcycles to their cart or wishlist.

Local storage is used to save cart and wishlist information in the browser, so the saved information remains available after refreshing the page.

## Important Note

This project is a front-end prototype. The cart and wishlist features work in the browser, but real ordering, online payment, and backend database functionality have not been implemented.

Motorcycle prices and specifications are provided for demonstration purposes. Actual prices, variants, and availability may differ depending on the showroom and current market conditions in Bangladesh.
